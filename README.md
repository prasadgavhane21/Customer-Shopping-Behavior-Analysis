# Customer Shopping Behavior Analysis

## Project Overview
This project analyzes customer shopping behavior using Python,
PostgreSQL, SQL, and Power BI.

The dataset contains 3,900 customer records and 18 columns.
The analysis explores customer preferences, purchasing patterns,
discount usage, subscriptions, and revenue trends.

## Technologies Used
- Python
- Pandas
- Jupyter Notebook
- PostgreSQL
- SQL
- Power BI
- DAX

## Project Workflow

### 1. Python Data Analysis
- Explored the dataset using Pandas.
- Used df.info() and df.describe().
- Handled missing review ratings.
- Standardized column names.
- Created age groups.
- Loaded data into PostgreSQL.

### 2. SQL Analysis
Analyzed:
- Revenue by gender.
- High-spending discount users.
- Top-rated products.
- Shipping type comparisons.
- Subscribers versus non-subscribers.
- Discount-dependent products.
- Customer segmentation.
- Top products by category.
- Repeat buyers and subscriptions.
- Revenue by age group.

### 3. Power BI Dashboard
Created an interactive dashboard featuring:
- Total customers.
- Average purchase amount.
- Average review rating.
- Subscription status.
- Revenue by category.
- Sales by category.
- Revenue by age group.
- Sales by age group.

## Project Structure
- data/: Dataset
- python/: Jupyter Notebook
- sql/: SQL queries
- powerbi/: Power BI dashboard
- screenshot/: Dashboard preview

## How to Run
1. Install dependencies using requirements.txt.
2. Open the Jupyter Notebook.
3. Configure PostgreSQL.
4. Execute the SQL queries.
5. Open the Power BI dashboard in Power BI Desktop.
